An example list of things that can stay small:

- **A project introduction:** explain what it does in a sentence.
- **A setup command:** make the first successful run easy to find.
- **An error message:** say what failed and what information is missing.
- **A personal website:** make the writing and work easy to reach.

Each item could become a longer article. A short note can also be enough when there is only one point to make.
